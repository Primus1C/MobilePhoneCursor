Импорт отчета торговой площадки

Обработка переносит отчёт Яндекс.Маркета в документы комиссии. Из листа серийных номеров создаются заказ (Инвойс продажи) и Расходная накладная по каждому номеру заказа. Продажи этих же строк собираются в один Отчет комиссионера.

Что вставить

Табличные поля заполняются вставкой из Excel (Ctrl+V), начиная с колонки A. Строки без серии и без номера заказа пропускаются, поэтому заголовки листа можно не удалять.

Серийные номера. По серии находится партия и номенклатура. Строки с одной датой и одним номером заказа попадают в один заказ. 

Платежи — отчёт о платёжном поручении. Строка с количеством больше нуля даёт цену отчёта и нужна для комиссии. Строка без количества — комиссия площадки, она суммируется по номеру заказа из колонки «сумма в долларах». В отчёт комиссионера такая строка сама не попадает.

Настройки

  • Дата. Если заполнена, она подставляется во все строки вместо даты из файла. Отчёт комиссионера записывается этой датой, время 10:00. Если дата пустая, заказы берут дату из файла, а отчёт — самую позднюю из них.
  • Контрагент, валюта, склад, статья отчета продажи — обязательны. Склад комиссии в расходной накладной берётся из карточки контрагента.
  • Перезаполнять существующие. Найденные заказ и расходная накладная перезаписываются. Без флажка уже существующая накладная не меняется, в строке результата будет сообщение. В отчёт комиссионера такой заказ всё равно попадает.
  • Проводить. Документы проводятся. Без флажка они только записываются. Для расходной накладной этот флажок также ставит признак «Окончательно».

Кнопки

Только поиск ничего не записывает. В таблице результата показываются уже существующие заказ и расходная накладная.

Импорт записывает документы. Перед записью серия должна находиться в партиях. Повторяющаяся пара «товар + номер заказа» на листе платежей считается ошибкой, такой заказ не записывается.

Какие документы получаются

Инвойс продажи — заказ комиссионера. Новый документ ставится на 9:00. В строках: номенклатура, количество, цена и сумма. Резерв не ставится. Уже существующий заказ ищется по номеру входящему и контрагенту.

Расходная накладная — комиссия, основание — заказ, в примечании номер заказа площадки. Новый документ ставится на 9:30. В строках партия и серия. Накладная ищется по примечанию, контрагенту и дню.

Отчет комиссионера — один на весь импорт, вид операции «Продажа». Поле над таблицей результата пустое: будет создан новый документ, ссылка затем появится в поле. Если документ выбран, он снимается с проведения и заполняется заново. Флажок «Перезаполнять существующие» на него не действует.

В табличную часть попадает товар, который есть в обоих листах одного заказа: и в серийных номерах, и в платежах. Серия берётся из серийных номеров. Строка только одного листа не записывается. В строке заполняется заказ — инвойс продажи этого номера. Цена и сумма строки берутся из расходной накладной, количество — из серийного номера. Цена отчёта — из платежа того же товара: в рублях, если валюта документа совпадает с валютой учёта, иначе в долларах. Комиссия заказа записывается в колонку «Сумма комиссии» со знаком минус и делится по строкам, попавшим в отчёт. Если у заказа несколько строк, сумма делится пропорционально сумме продажи, остаток копеек остаётся на последней строке. Сумма комиссии в шапке равна итогу строк. Документ-основание не заполняется.

В таблице результата ссылки на заказ и накладную открываются щелчком. Текст ошибки по заказу показывается в последней колонке.
