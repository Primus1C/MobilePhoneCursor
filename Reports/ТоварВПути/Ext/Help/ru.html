Отчет «Товар в пути»

Отчет показывает по инвойсам закупки, сколько товара уже принято на склад, сколько еще ожидается (в пути), какая сумма оплачена и какой долг перед поставщиком.

Как строится отчет

В отчет попадают инвойсы, по которым есть расчеты с поставщиком (регистр «Расчеты по инвойсам») на дату окончания периода.

По каждому такому инвойсу собираются данные из двух регистров:

  • Расчеты по инвойсам — долг на конец периода и оплаты документами «Движение денег».
  • Оприходование номенклатуры — сколько товара принято приходными накладными и сколько еще осталось к поступлению.

Остатки считаются на конец периода отчета. Обороты (оплаты и приемка) — с начала учета по эту дату.

Строки группируются по поставщику, внутри — по инвойсу (номер и дата инвойса поставщика, сумма инвойса). Вариант «Подробно по документам» дополнительно показывает документы, которыми отражены оплаты и приемка.

Какими данными заполняются колонки

  • Оплачено — сумма оплат по инвойсу документами «Движение денег».
  • Долг — остаток расчетов по инвойсу на конец периода (при необходимости пересчитан в валюту инвойса поставщика по курсу документа).
  • Принято, количество / сумма — товар, уже оприходованный приходными накладными (расход регистра оприходования).
  • Ожидаем, количество / сумма — товар, который еще не принят на склад (остаток регистра оприходования: инвойс проведен, приходной нет или она неполная).
  • Ожидаем по оплате — ожидаемая сумма минус долг (сколько из товара в пути уже оплачено).

Отборы

Период отчета и отбор по контрагенту (с учетом групп поставщиков).

Инвойсы без расчетов с поставщиком в отчет не попадают, даже если по ним есть товар в пути.
